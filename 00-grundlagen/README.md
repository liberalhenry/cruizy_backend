# Grundlagen — die Wahrheitsquellen

Hier liegen die Dokumente, auf die sich alles andere im Projektordner beruft. **Die Handbücher werden nicht bearbeitet.** Wo etwas nicht mehr stimmt, entsteht eine neue Fassung oder ein Widerspruch wird im arbeitenden Dokument benannt — nie eine stille Korrektur.

**Rangfolge bei Widerspruch (seit 19.09.2026):** Grundsatzbeschluss → Handbuch A / Handbuch B → abgeleitete Dokumente. Die Grundsatzbeschlüsse sind der Ort für Regeln, die **nach** dem Erscheinen der Handbücher beschlossen wurden und deshalb nicht in sie hineingeschrieben werden können.

## Die fünf Regeln im Umgang mit den Handbüchern

1. **Nicht bearbeiten.** Kein Satz wird geändert, auch kein offensichtlicher Fehler.
2. **Widersprüche benennen, nicht auflösen.** Wo ein Handbuch sich selbst oder das andere widerspricht, steht das im arbeitenden Dokument mit Fundstelle — die Entscheidung treffen die Gründer.
3. **Nachgerechnetes schlägt Abgeschriebenes.** Wo eine eigene Rechnung vom Handbuch abweicht, gilt die Rechnung und die Abweichung wird ausgewiesen. Beispiel: der Kapitalbedarf (`../40-finanzen-foerderung/kapitalbedarf-gegenrechnung.md`).
4. **Ein späterer Beschluss geht vor.** Wo ein Grundsatzbeschluss oder eine entschiedene Nummer aus `../01-steuerung/offene-entscheidungen.md` eine Stelle des Handbuchs überholt, gilt der Beschluss — und die überholte Stelle wird dort, wo sie zitiert wird, als überholt gekennzeichnet. Ob die Handbücher selbst je eine Fassung 2 bekommen, ist **Nr. 81**.
5. **Was im Handbuch fehlt, ist eine Festlegung, keine Tatsache.** Wo die Handbücher schweigen, trifft die Produktspezifikation eine ausdrücklich gekennzeichnete Festlegung (FV-01 bis FV-90) — sie ist von den Gründern zu bestätigen (**Nr. 68**).
